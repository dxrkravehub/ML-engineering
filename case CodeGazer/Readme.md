# 👁️ VLM-Powered QA: Первый в мире ИИ, который *видит* и автоматизирует поиск багов 
# *(на которые у опытных QA уходит от 15 минут!)*

## 🚀 Обзор проекта
Этот проект представляет собой **Мультимодальную Визуально-Языковую Модель (VLM)**, специально разработанную для **автоматизации контроля качества (QA)**. В отличие от традиционных систем, наш VLM не просто анализирует логи или отчеты — он "видит" проблему на скриншоте или снимке интерфейса, понимает контекст и генерирует отчет.

**Главное преимущество:** Впервые ИИ не просто "понимает" баг, он **видит его** в визуальном контексте.

## ✨ Уникальная функциональность (Key Features)

* **Визуальное обнаружение дефектов:** Использует модель Florence-2 для анализа скриншотов, выделения ключевых элементов и понимания визуального контекста интерфейса.
* **Контекстный анализ и генерация отчетов:** Использует **Gemini LLM** для интерпретации визуальных данных от Florence-2, сравнения их с ожидаемым поведением и генерации подробного баг-репорта (включая шаги воспроизведения и ожидаемый результат).
* **Гибкость:** Поддерживает различные стили анализа и форматы вывода, настраиваемые через параметры Florence-2.

## 🛠️ Технический стек

| Компонент | Роль | Модель/Инструмент |
| :--- | :--- | :--- |
| **VLM-Ядро (Визуальный Анализ)** | Анализ изображений, обнаружение и описание элементов. | **Florence-2** |
| **LLM-Интерпретатор** | Генерация отчета, контекстуализация, принятие решений (QA Logic). | **Gemini LLM** |

## ⚙️ Запуск и использование

### 1. Предварительные требования
* Python 3.x
* Установите необходимые библиотеки (Florence-2, SDK для Gemini LLM).

### 2. Запуск
Поочередно запустите все ячейки в предоставленном Jupyter Notebook.

### 3. Настройка и вариации
Ознакомьтесь с параметрами модели **Florence-2** для управления глубиной анализа:
* **Prompting:** Изменяйте входной текстовый промпт, чтобы направлять модель на поиск конкретных дефектов (например, "Опиши невыровненный элемент" или "Найди ошибки в тексте на скриншоте").
* **Task Variations:** Экспериментируйте с различными задачами Florence-2 (например, Image Captioning для общего описания, Object Detection для локализации бага).

## 💡 Примеры сценариев

| Задача | Ввод | Ожидаемый вывод (от Gemini) |
