# Приложение для обработки документов

Этот проект представляет собой веб-приложение на Streamlit, предназначенное для обработки документов в форматах PDF и XLSX с целью извлечения ключевой информации. Оно использует OCR (оптическое распознавание символов) для PDF-файлов и прямое извлечение данных для XLSX-файлов. Также предусмотрена возможность использования Gemini LLM для постобработки и структурирования извлеченного текста из PDF.

## Используемые технологии и обоснование выбора

Для обработки документов в этом проекте используются следующие технологии:

*   **OCR.Space API**: Используется для выполнения оптического распознавания символов на изображениях, полученных из PDF-файлов. Этот сервис предоставляет удобный API для извлечения текста.
*   **fitz (PyMuPDF)**: Библиотека для работы с PDF-документами. Используется для открытия PDF-файлов и преобразования их страниц в изображения для последующего OCR. Выбран из-за его скорости и эффективности в работе с PDF.
*   **PIL (Pillow)**: Библиотека для работы с изображениями. Применяется для обработки изображений страниц PDF перед передачей их в OCR.
*   **requests**: Библиотека для выполнения HTTP-запросов. Используется для взаимодействия с внешними API, такими как OCR.Space.
*   **pandas**: Мощная библиотека для работы с данными. Используется для чтения и обработки данных из XLSX-файлов.
*   **openpyxl**: Библиотека для чтения и записи файлов Excel 2007+ (.xlsx/.xlsm/.xltx/.xltm). Используется pandas для работы с XLSX.
*   **google-generativeai (Gemini LLM)**: Используется опционально для постобработки сырого текста, полученного из PDF через OCR. Gemini LLM помогает структурировать неструктурированный текст и извлекать определенные поля в формате JSON. Выбор Gemini LLM обусловлен его способностью понимать контекст и извлекать нужную информацию из текста свободной формы.

*(Примечание: Технологии trOcr, donut, LayoutLM являются передовыми моделями для распознавания и анализа документов. Хотя они не были напрямую интегрированы в текущую версию этого кода, концептуально они выполняют аналогичные задачи OCR и структурного анализа, как и комбинация OCR.Space API и Gemini LLM, используемая здесь. Выбор между ними зависит от конкретных требований к точности, скорости, стоимости и сложности интеграции. В данном проекте была продемонстрирована работа с доступными API и моделями для достижения схожих результатов.)*
