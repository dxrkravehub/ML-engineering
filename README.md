# Анализ государственных закупок Казахстана на предмет рисков

Данный проект направлен на анализ данных о государственных закупках в Казахстане для выявления потенциальных рисков, таких как завышение цен, частые победы одних и тех же поставщиков, искусственное дробление закупок и низкая конкуренция.

## Используемые библиотеки

*   `pyngrok`
*   `streamlit`
*   `pandas`
*   `numpy`
*   `scikit-learn`
*   `matplotlib`
*   `seaborn`
*   `playwright`

## Шаги выполнения

1.  **Установка библиотек**: Установлены все необходимые библиотеки.
2.  **Создание `requirements.txt`**: Сформирован файл со списком зависимостей.
3.  **Парсинг данных**: Загрузка и начальная обработка данных из файла `contract_20-06-2025_export.xls`.
4.  **Скрейпинг описаний (опционально)**: Извлечение краткого содержания договоров с веб-сайта (при необходимости).
5.  **Предобработка данных**: Очистка и трансформация данных для анализа.
6.  **Выявление рисков**: Анализ данных на предмет завышения цен, частых побед, дробления и низкой конкуренции.
7.  **Визуализация результатов**: Создание отчета или дашборда с выявленными рисками.
